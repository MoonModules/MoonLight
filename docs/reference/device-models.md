# Device models

The devices MoonLight installs on, with what each one supports and the settings it brings: the supported hardware. Pick yours in the [web installer](https://moonmodules.org/MoonLight/install/), and MoonLight arrives with the pins, drivers and services of that device filled in. The [Devices](../moonmodules/core/devices.md) page lists the devices on your network.

The cards are drawn from the installer's catalog, `mooninstaller/deviceModels.json`. Each card's anchor is its name in lowercase with hyphens, `#esp32-s3-devkitc-1` for the ESP32-S3 DevKitC-1, which a device's System card links to.
