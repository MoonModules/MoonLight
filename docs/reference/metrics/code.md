## How a finding is solved

Each rule is a code smell with a named move from the refactoring catalog, the table in [coding standards, from a finding to a fix](../../contributing/coding-standards.md#from-a-finding-to-a-fix). The commit names the move.

- **complex function** (cyclomatic complexity > 10): a chain on one value becomes a table; a switch on a state becomes one method per state.
- **long function** (> 60 lines of code): Extract Function: a named step a reader can skip.
- **deeply nested** (control flow nested deeper than 3): a guard becomes an early return; an inner loop becomes a function.
- **long parameter list** (> 7 parameters): Introduce Parameter Object: the parameters that travel together become one struct.
- **duplicated block** (>= 5 lines also found elsewhere): Extract Function, or Pull Up Method into the shared base: one home for the block.
- **large file** (> 1000 lines): Extract Class, Move Function: a module per concern.
- **blocking call on the render path** (a call from tick, tick20ms or tick1s that can block or allocate): Move the work off the render thread (a worker, a cached value, a deferred apply), or annotate a callee that cannot block.
- **platform code outside src/platform** (a vendor header or a platform #ifdef outside src/platform): Move it behind a function in src/platform, and branch on platform_config.h with if constexpr.
- **light include in core** (a src/core file including a light/ header): Dependency Inversion: core declares the interface, and the light domain implements and registers it.
- **module type in the UI** (a registered type's name as a string literal in src/ui): Replace Conditional with Polymorphism: the module declares what the UI needs (a control, a role, a flag) and the UI reads it.
- **name spread** (a type named in more than 10 files beyond its own): Move Function, self-registration: a concept in one place, which callers reach through its role or an interface.
- **large stack frame** (a function whose stack frame is over 512 bytes): Move the large local into a member or a ScratchBuffer, sized once, so no task's stack pays for it.
- **raw allocation in light** (an array new, malloc or platform::alloc in src/light outside ScratchBuffer): Replace the allocation with a ScratchBuffer member, which owns, sizes and frees it.
- **mutable static state** (a static variable in src/core or src/light that is not const or constexpr): the state becomes the module's own: a member, a ScratchBuffer taken in prepare(), or a caller-owned workspace.
