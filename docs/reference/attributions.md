# Attributions

The people, projects and published algorithms whose work shaped MoonLight. We study their thinking with respect and write our own code against our architecture. A module's `@attribution` names an entry by any of its names, a person and their company or handle written as one entry, and the module's help links it there. A picture is a Wikimedia Commons file, named after the link as `File:<name>`, and an entry linking GitHub shows its avatar. A name not listed yet is still allowed: it shows as written until it is added here. The modules that name an entry are read from their headers when the site is built.
