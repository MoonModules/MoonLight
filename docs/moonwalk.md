# MoonWalk { .mm-visually-hidden }

Pick a task from **Next**, or click a process on the map, to read its steps beside the map; search or filter to find one. Ready to install? Open the [web installer](https://moonmodules.org/MoonLight/install/).

<div id="mm-map" class="mm-map"></div>

Every MoonLight process on one map: a column per stage, a box per process holding its steps. The border says whose it is: green an end user's, blue a contributor's, purple the product owner's, orange an agent's, gray CI's. Click a process to read it beside the map.

On a device, the help on every card links the steps it takes part in and opens this map at them:

<video src="assets/moontube/14-help-and-moonwalk.webm" controls playsinline width="720" title="Help on every card and control, a help link opening MoonWalk at its step, and a control's tests on the test page."></video>

The map is drawn from the stage files under [moonwalk/](../moonwalk/), one per stage; [the MoonWalk model](explanation/architecture/moonwalk.md) describes them. How to use the map, run it and write a process: [the MoonWalk reference](reference/moonwalk.md).
