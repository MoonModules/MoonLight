# MoonWalk

MoonWalk is every process MoonLight has, from reading the docs to a release, on one map. Each column is a stage of the journey, each box a process, and a process that has its steps written holds them inside. The border says whose it is: green an end user's, blue a contributor's, purple the product owner's, orange an agent's and grey CI's. An arrow points from a process to the one that builds on it.

Zoom out for the whole journey and in for the steps. Search finds a process by its title, its goal or any step. The filters narrow it to one actor or to the systems you pick, the parts the [architecture](explanation/architecture/index.md) names, and can leave out what you marked done. Switch the columns from stage to system to see the same processes from the architecture's side. The map button in the header opens the map at the page you came from. Your done marks stay in this browser.
