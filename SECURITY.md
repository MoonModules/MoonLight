# Security policy

## Supported versions

Fixes land on `main`, which ships as the latest pre-release, and in the next tagged release. Update to the latest release to receive them.

## Reporting a vulnerability

Report it privately through GitHub: [Report a vulnerability](https://github.com/MoonModules/MoonLight/security/advisories/new). A private report lets the fix ship before the details are public. A maintainer answers in the advisory, and the fix and the advisory are published together.

## The security model

What a device trusts, what guards it, and how to secure an installation: [Security](https://moonmodules.org/MoonLight/explanation/security/).
